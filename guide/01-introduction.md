# 認識 Operoid

> 適用版本：v0.5.11。本章介紹產品定位與核心概念——之後每一章都會用到這些詞彙。

## Operoid 是什麼

**Operoid 是一套開源的 AI 員工作業系統**：AI 代理——**員工（Employee）**——在共享的工作空間裡承擔持久的職責，並且始終在「由人類畫定、由伺服器強制執行、事後可稽核」的邊界內工作。它以 Rust（常駐服務＋Tauri v2 桌面殼）與 Vue 3 打造，**跑在你自己的硬體上**——你自己的電腦，或公司自己的內網。

市面上多數 Agent 產品已經能在你關掉視窗後繼續工作——「持續運作」已是標配。Operoid 回答的是更根本的問題：***我憑什麼讓它做？***

- 它到底被允許做什麼？
- 被允許知道什麼？
- 當它做錯了，誰來負責？

今天的 AI 像一位出色的**顧問**：給完建議就離開，沒有身份、沒有授權範圍、無從課責。**員工**不一樣：員工加入組織、承擔成果、持續負責。要讓 AI 做到同樣的事，它需要任何一位新進員工都需要的東西：

| 新進員工需要 | Operoid 給的 |
|---|---|
| 由組織核發、隨時可收回的**身份** | 每位員工以自己的 token 認證；身份出自 token 鏈，不出自呼叫端的自稱 |
| 寫明「不必請示就能做什麼」的**委任** | 動作類別登記表：以動作類別為單位授權，從嚴預設、會屆期、須重簽 |
| 寫明「可以知道什麼」的**權限** | 知識權限在**檢索之前**由伺服器程式碼強制執行，缺政策＝拒絕（fail closed） |
| 經手的每件事都留下**紀錄** | 成果物版本化、承諾可追蹤；每次特權檢索都留一張收據 |

這四件事在 Operoid 是**架構**，不是加購選項。

## 一套程式碼，兩種版本

| | 個人版 | 企業版 |
|---|---|---|
| 資產 | 桌面安裝檔 | `operoid-enterprise-*` 部署包 |
| 執行位置 | 使用者自己的電腦 | 公司內網伺服器 |
| 設定 | 安裝即用 | 一條引導式指令：`oserver configure` |
| 存取 | 桌面應用 | 瀏覽器：`/admin`、`/manager`、`/user`——密碼登入＋角色式權限 |

個人版安裝見[第 03 章](03-install-personal.md)，企業版見[第 04 章](04-install-enterprise.md)。本指南以個人版為主，企業版的日常操作集中說明於[第 16 章](16-enterprise-consoles.md)。

## 員工的工作循環

Employee 因**觸發（Trigger）**而醒來：排程、進來的 Email、經理人或其他人類員工的訊息。醒來後恢復上下文，在自己的沙箱工作區裡工作（讀檔、改檔、執行指令、查詢知識——全部在你設定的模板級授權之下），然後回去休眠。

在對話裡你看得見它工作：每個工具呼叫、參數、耗時，然後是一份乾淨的 Markdown 回覆。當決策超出它的授權，它不猜測——它**提案**，由人類核可。

## 核心概念速覽

這些詞彙貫穿整份指南與產品介面：

| 概念 | 一句話 | 深入閱讀 |
|---|---|---|
| **員工（Employee）** | 有身份、有職責、持續工作的 AI 代理；由模板部署出多個獨立實體 | [架構手冊 Ch.04](../handbook/Chinese/04-Employee.md) |
| **腦（Brain）** | 由 GBrain 知識引擎管理的知識本體；員工由此查證作答 | 本指南[附錄 A](appendix-a-gbrain.md)、[Ch.05](../handbook/Chinese/05-Brain.md) |
| **成果物（Artifact）** | 員工工作的產出；版本化、歸工作空間所有，不歸對話 | [Ch.06](../handbook/Chinese/06-Artifact.md) |
| **承諾（Commitment）** | 員工答應完成的事：有完成條件、挺得過重啟、連續失敗自動交回人類 | [Ch.11](../handbook/Chinese/11-Commitment.md) |
| **觸發（Trigger）** | 喚醒員工的事件源：排程、Email、訊息 | [Ch.12](../handbook/Chinese/12-Trigger.md) |
| **動作類別登記表（Action Registry）** | 人類畫定的委任界線：哪些類別的行動可免個案核可自動執行 | 本指南[第 13 章](13-governance.md)、[Ch.20](../handbook/Chinese/20-Security.md) |
| **技能（Skill）** | 程序性知識（某類工作怎麼做），**不是**授權；行動仍受工具允許清單約束 | 本指南[第 11 章](11-skills.md) |
| **Runtime（執行引擎）** | 喚醒員工、恢復上下文、讓它工作、再讓它休眠——管理執行，從不管理思考 | [Ch.13](../handbook/Chinese/13-Runtime.md) |
