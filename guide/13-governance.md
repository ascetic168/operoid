# 治理：登記表與知識授權

> 本章撰寫中。概念閱讀：[架構手冊 Ch.20 安全](../handbook/Chinese/20-Security.md)、[界線的形狀](../journal/界線的形狀_朱國棟.pdf)。

## 預定內容

- 動作類別登記表（「設定→登記表」）：委任三層——人裁決層／圍欄自動層／有主自動層
- 每個類別的三問：可逆？影響範圍（內部／客戶／支出／安全／權利）？問責人？
- 登記的入場條件：可逆＋內部影響＋具名問責＋未來屆期＋放寬證據（缺一存檔被拒）
- 全域保險絲：保險絲關鍵字、每週提案預算、抽審分歧門檻（預設 0.2）
- 從嚴預設：未登記類別一律送人類核可；收緊永遠允許
- 知識授權（「設定→知識授權」）：知識政策（DENY→ALLOW→fail closed）、保密等級硬天花板、principals 與 API token、TTL grants、知識範圍
- 檢索收據（Retrieval Receipt）：每次特權檢索留下紀錄
