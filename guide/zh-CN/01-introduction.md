# 认识 Operoid

> 适用版本：v0.5.11。本章介绍产品定位与核心概念——之后每一章都会用到这些词汇。

## Operoid 是什么

**Operoid 是一套开源的 AI 员工操作系统**：AI 代理——**员工（Employee）**——在共享的工作空间里承担持久的职责，并且始终在「由人类划定、由服务器强制执行、事后可审计」的边界内工作。它以 Rust（常驻服务＋Tauri v2 桌面壳）与 Vue 3 打造，**跑在你自己的硬件上**——你自己的电脑，或公司自己的内网。

市面上多数 Agent 产品已经能在你关掉窗口后继续工作——「持续运作」已是标配。Operoid 回答的是更根本的问题：***我凭什么让它做？***

- 它到底被允许做什么？
- 被允许知道什么？
- 当它做错了，谁来负责？

今天的 AI 像一位出色的**顾问**：给完建议就离开，没有身份、没有授权范围、无从问责。**员工**不一样：员工加入组织、承担成果、持续负责。要让 AI 做到同样的事，它需要任何一位新员工都需要的东西：

| 新员工需要 | Operoid 给的 |
|---|---|
| 由组织核发、随时可收回的**身份** | 每位员工以自己的 token 认证；身份出自 token 链，不出自调用端的自称 |
| 写明「不必请示就能做什么」的**委任** | 动作类别登记表：以动作类别为单位授权，从严预设、会届期、须重签 |
| 写明「可以知道什么」的**权限** | 知识权限在**检索之前**由服务器代码强制执行，缺政策＝拒绝（fail closed） |
| 经手的每件事都留下**记录** | 产出物版本化、承诺可追踪；每次特权检索都留一张收据 |

这四件事在 Operoid 是**架构**，不是加购选项。

## 一套代码，两种版本

| | 个人版 | 企业版 |
|---|---|---|
| 资产 | 桌面安装包 | `operoid-enterprise-*` 部署包 |
| 运行位置 | 用户自己的电脑 | 公司内网服务器 |
| 配置 | 安装即用 | 一条引导式指令：`oserver configure` |
| 访问 | 桌面应用 | 浏览器：`/admin`、`/manager`、`/user`——密码登录＋角色式权限 |

个人版安装见[第 03 章](03-install-personal.md)，企业版见[第 04 章](04-install-enterprise.md)。本指南以个人版为主，企业版的日常操作集中说明于[第 16 章](16-enterprise-consoles.md)。

## 员工的工作循环

Employee 因**触发（Trigger）**而醒来：定时任务、进来的 Email、经理人或其他人类员工的消息。醒来后恢复上下文，在自己的沙箱工作区里工作（读文件、改文件、执行指令、查询知识——全部在你设定的模板级授权之下），然后回去休眠。

在对话里你看得见它工作：每个工具调用、参数、耗时，然后是一份干净的 Markdown 回复。当决策超出它的授权，它不猜测——它**提案**，由人类核可。

## 核心概念速览

这些词汇贯穿整份指南与产品界面：

| 概念 | 一句话 | 深入阅读 |
|---|---|---|
| **员工（Employee）** | 有身份、有职责、持续工作的 AI 代理；由模板部署出多个独立实体 | [架构手册 Ch.04](../../handbook/Chinese/04-Employee.md) |
| **脑（Brain）** | 由 GBrain 知识引擎管理的知识本体；员工由此查证作答 | 本指南[附录 A](appendix-a-gbrain.md)、[Ch.05](../../handbook/Chinese/05-Brain.md) |
| **产出物（Artifact）** | 员工工作的产出；版本化、归工作空间所有，不归对话 | [Ch.06](../../handbook/Chinese/06-Artifact.md) |
| **承诺（Commitment）** | 员工答应完成的事：有完成条件、挺得过重启、连续失败自动交回人类 | [Ch.11](../../handbook/Chinese/11-Commitment.md) |
| **触发（Trigger）** | 唤醒员工的事件源：定时任务、Email、消息 | [Ch.12](../../handbook/Chinese/12-Trigger.md) |
| **动作类别登记表（Action Registry）** | 人类划定的委任界线：哪些类别的行动可免个案核可自动执行 | 本指南[第 13 章](13-governance.md)、[Ch.20](../../handbook/Chinese/20-Security.md) |
| **技能（Skill）** | 程序性知识（某类工作怎么做），**不是**授权；行动仍受工具允许清单约束 | 本指南[第 11 章](11-skills.md) |
| **Runtime（执行引擎）** | 唤醒员工、恢复上下文、让它工作、再让它休眠——管理执行，从不管理思考 | [Ch.13](../../handbook/Chinese/13-Runtime.md) |
