# 員工管理：模板與實體

> 適用版本：v0.5.11。員工功能需先開啟「設定 → 應用程式 → 啟用 Agent-OS」。概念閱讀：[架構手冊 Ch.04 員工](../handbook/Chinese/04-Employee.md)。

## 兩層模型：模板 → 實體

- **員工模板**——職務的定義：對應哪顆腦、職責描述、允許用哪些工具。可重用。
- **員工實體**——從模板部署出的「那位員工」：獨立的名字、獨立的狀態與歷史。一個模板可部署多個互不干擾的實體。

## 員工模板（「員工模板」頁）

按「新增模板」：

| 欄位 | 說明 |
|---|---|
| 名稱 | 例如「採購助理」 |
| 對應腦 | 這類員工查證作答的知識來源（一個模板對應一個腦） |
| 角色（選填） | 機器可讀的角色代號，例如 `procurement` |
| 職責描述（選填） | 部署時複製到每個實體的職說明，例如「負責週報彙整與供應商詢問」 |
| 工具授權 | **未勾選的工具員工看不到**——這是最基本的委任界線 |

### 工具授權

- **預設集**：think（深思）／search（檢索）／send（溝通）——知識與溝通的基本組合。
- **允許寫入筆記**：員工可將產出寫到專屬產出目錄（預設 `~/employee-output`，不入圖譜；人工審閱後移入來源 repo 走 sync 晉升）。
- **允許讀取／寫入／編輯工作區檔案**：報告草稿、CSV 等自有工作區內容；編輯為精確字串替換（須先讀取）。
- **允許執行工作區指令**（進階）：資料處理、跑公司腳本——給予前請審慎評估。

模板可重新命名、刪除；「模板詳情」可檢視建立時間與設定。

## 員工實體（「員工實體」頁）

「部署新實體」：選來源模板、填實體名稱（例如 `Steve@TW`）、可填對外 email（供[郵件橋接](14-email-bridge.md)路由）。

實體卡片上**按右鍵**管理：

| 動作 | 說明 |
|---|---|
| 對話… | 開啟聊天（見下節） |
| 溝通… | 發一則訊息給這位員工（它會被喚醒處理） |
| 監看… | 開啟監看面板（見下節） |
| 交辦… | 建立承諾：給**承諾標題**（如「追蹤蝕刻良率事件到結案」）與**完成條件**（如「產出含行動時間表與財務影響的報告」）——建立後員工立即醒來，工作到完成 |
| 開啟產出目錄 | 開啟此員工的輸出資料夾 |
| 重新命名／刪除實體 | — |
| 封存… | 歷史（對話／事件／產出）保留、不再被喚醒；隨時可「解除封存」。已封存員工集中在清單下方，可追溯 |

## 對話

- 你看得見它工作：提問與 Markdown 回覆之間，列出**每個工具呼叫**——工具名、參數、耗時；回答以串流方式即時輸出。
- 「{n} 個工具呼叫」可展開檢視完整軌跡；「思考中」表示正在推理。
- **清除對話**只清訊息——工作產出（Artifact）與承諾（Commitment）保留。
- 員工工作中按「停止」是**合作式停止**：在下一個步驟邊界優雅停止；再傳訊息或交辦即可恢復。

## 監看面板

「監看…」打開這位員工的即時儀表板：

- **待核可提案**／**自動啟用（登記類別）**——哪些行動在等你、哪些依登記表自動啟用；
- **抽審**——對自動啟用的承諾標記「歸類正確／歸類錯誤」，餵給分歧率統計；
- **進行中的承諾、目前工作、近期產出、生命週期事件、已決策承諾、已完成工作**。

## 子代理

自 v0.5.7 起，員工可派生**子代理（spawn_subagent）**：一次性的唯讀研究上下文，用來查資料、讀文件後把結論帶回母任務——不能寫任何東西。步數保險絲預設 20 步（`subagent_max_steps`，見[第 17 章](17-config-reference.md)）。

## 員工之間的溝通

員工之間有內部信箱（可互通訊息、查同事名單），由「設定 → 應用程式」的 `internal_mail_enabled` 總閘控制（預設開；關閉＝工具不存在）。企業版裡，使用者也能從自己的主控台與**同事的**員工對話（自 v0.5.9 起）。
