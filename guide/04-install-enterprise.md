# 安裝企業版

> 本章撰寫中。完整部署流程請直接參閱 [DEPLOYMENT.md](../DEPLOYMENT.md)——本章只做總覽與名詞對照。

## 預定內容

- 部署包內容清單：oserver、obridge、三個角色前端、DEPLOYMENT.md、operoid.example.toml、mm-bridge
- `oserver configure` 部署精靈流程總覽（前置檢查→gbrain→host/port→TLS→LLM key→管理員帳號）
- `oserver install / uninstall / status`：開機服務（Windows 服務／systemd／launchd）
- 瀏覽器存取：`/admin`、`/manager`、`/user`
- 何時查 DEPLOYMENT.md 的哪一節（索引表）
