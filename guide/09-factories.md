# 文件工廠

> 本章撰寫中。

## 預定內容

- 工廠是什麼：把原始文件轉成結構化知識頁寫入腦
- 內建工廠類型：圖片、people、companies、meeting、projects、concepts、inbox（速記）、自動（分派）
- schema pack：v1（6 工廠）與 gbrain-base-v2（15 型）、unify-types 遷移
- 流程：拖放 → 轉換（MinerU 階梯：簡單 PDF 快速路徑／複雜 PDF 完整轉換）→ LLM 結構化 → 預覽編輯 →「Sync 到腦」
- 圖片工廠：註解必填、多模態嵌入、image_of 連結
- conversion-report 與常見轉換訊息解讀
- 保密等級／圈子寫入（企業模式，自 Enterprise C′ 起）
