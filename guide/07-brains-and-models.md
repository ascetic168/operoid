# 腦與模型設定

> 本章撰寫中。GBrain 概念先行閱讀：[附錄 A](appendix-a-gbrain.md)。

## 預定內容

- 「腦」頁：新增腦（登錄既有／建立新腦）、設為作用中、來源（sources）管理、同步全部
- 移除來源：封存（保留 72 小時）vs 永久刪除
- 「設定→模型」：GBrain config.json 是權威來源；chat 模型、四個 tier（utility/reasoning/deep/subagent）、embedding 模型與維度
- LLM 端點與 API key（環境變數）
- gbrain 傳輸：MCP（預設）或純 CLI
- 「設定→服務」：能力矩陣、本地服務、Obridge 設定
