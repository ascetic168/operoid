# 安裝個人版

> 本章撰寫中。先行參閱：[README 開始使用](../README.zh-TW.md)。

## 預定內容

- 到 GitHub Releases 下載對應平台安裝檔：Windows（安裝精靈）、macOS（.dmg）、Linux（.deb／.rpm／AppImage）
- 安裝內容：桌面應用＋內建 oserver 服務與 obridge
- 首次啟動：前置程式檢查（git／bun／gbrain）與安裝連結
- 設定 → 應用程式：「版本與更新」——更新提示／自動更新（預設關閉）的差異
- 升級與解除安裝注意事項（服務會如何處理）
